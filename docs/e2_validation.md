# Stage E2 validation: ratings model and back-test

Generated by `python -m altpl.build_e2`. Every number below is a model estimate from real results and bookmaker odds, not a fact. The spreadsheet `data/processed/e2_backtest.xlsx` has every table in full.

## Model

Dixon-Coles Poisson model, one attack and one defence rating per club per season, home advantage per season plus a per-division adjustment, fitted to all 46,036 league matches 2008/09–2025/26 in tiers 1–5 at once. Divisions are put on one scale by tying each club's ratings to its previous season's (a random walk), so clubs that move between divisions fix the gap between them. Bookmaker odds enter as the expected goals they imply, counted as extra fractional goals. See `altpl/ratings.py` and the E2 entries in `docs/assumptions_log.md`.

- Season-to-season change in a club's ratings (sigma): **0.15** per season, chosen by pre-season log-loss.
- Weight on the odds (omega): **16.0** (1 = the market's view of a match counts as much as its score), chosen by held-out log-loss.
- Dixon-Coles rho: -0.025. Average home advantage: 0.256 on the log scale; 2020/21 (no crowds): 0.182.
- Ratings are scaled so the average Premier League club-season has attack 0. Strength = attack + defence; a 0.1 gap is roughly 10% more goals scored and 10% fewer conceded.
